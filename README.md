# **💻 Portafolio Personal**

## Portafolio web personal enfocado en presentar mi perfil como desarrolladora de software en formación, mis habilidades y mis proyectos de programación.

<img width="975" height="557" alt="image" src="https://github.com/user-attachments/assets/2627ed1b-1139-4ad4-bf4f-f97e33f01929" />

### ✨ Características

- Inicio: presentación personal con una animación de texto estilo terminal.

- Sobre mí: información sobre mi formación e intereses en programación, tecnología y robótica.

- Habilidades: muestra de tecnologías y herramientas que he trabajado, como C++, Python, PSeInt, HTML y Scratch.

- Proyectos: visualización dinámica de proyectos con sus descripciones y enlaces a sus repositorios.

- Contacto: acceso a mi perfil de GitHub.

### 🛠️ Tecnologías utilizadas:

- *HTML5: **estructura de la página web.***

- *CSS3: **diseño y estilos visuales.**

- *JavaScript: **animaciones y generación dinámica de las tarjetas de proyectos.***

- *JSON: **almacenamiento de los datos de los proyectos que se muestran en el portafolio.***

  
### 🚀 Cómo ejecutar el proyecto

1. Clona o descarga este repositorio.

2. Abre la carpeta en Visual Studio Code.

3. Ejecuta index.html utilizando la extensión Live Server.

4. Navega por las secciones y consulta los proyectos disponibles.

***Nota: se recomienda utilizar Live Server para permitir que JavaScript cargue correctamente los datos de projects.json.***
